Layer structure: each of the 30 text decoder layers contains self-attention (Q/K/V projections + RoPE + GQA + output proj) + dense MLP (gate/up/down proj) + MoE block (router + 128 experts). Sliding layers use head_dim=256, 8 KV heads (GQA 2×). Full-attention layers use head_dim=512, 2 KV heads (GQA 8×).
view / layout op differs between sliding and full-attention
